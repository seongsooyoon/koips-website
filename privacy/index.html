개인정보처리방침

시행일: 2026년 11월 13일 · English summary below

한국정책연구소(KOIPS, 이하 “연구소”)는 「개인정보 보호법」 등 관련 법령을 지키며, 정보주체의 개인정보를 보호하기 위해 다음과 같이 개인정보처리방침을 정합니다. 이 방침은 연구소 홈페이지(koips.org)와 연구소가 운영하는 서비스(정보공개 답변서 작성기, 연구소 유튜브 채널 운영 도구 등)에 적용됩니다.

1.처리 목적

  • 연구용역·상담 문의 접수와 회신
  • 연구소 서비스 제공 및 이용 요금 안내·정산
  • 연구소가 직접 소유·운영하는 유튜브 채널의 영상 업로드, 채널·영상 관리, 성과(통계) 확인
  • 연구소 업무 일정 관리

2.처리하는 개인정보 항목

구분항목수집 방법
상담 문의기관명, 담당자 이름, 연락처(전화·이메일), 문의 내용전화·이메일로 정보주체가 직접 제공
서비스 이용이용 기관명, 담당자 연락처, 결제·이용 기록서비스 신청 시 직접 제공
Google 계정 연동
(연구소 내부 도구)		OAuth 인증 토큰, 연구소 소유 유튜브 채널의 채널·영상 정보와 통계, 연구소 캘린더 일정연구소 관리자가 Google 로그인으로 직접 허용

홈페이지는 회원가입을 받지 않으며, 방문자 개인을 식별하는 쿠키를 사용하지 않습니다.

3.Google 사용자 데이터 처리 (Google API Services)

연구소의 내부 업무 도구는 연구소 관리자 본인이 허용한 범위에서만 다음 Google API 권한을 사용합니다.

권한사용 목적
YouTube 업로드 (youtube.upload)연구소 채널에 직접 제작한 영상 업로드
YouTube 관리 (youtube.force-ssl)연구소 채널 영상의 제목·설명·썸네일·재생목록·댓글 관리
YouTube 읽기 / Analytics 읽기연구소 채널의 영상 목록과 조회수 등 성과 확인
Google Calendar연구소 업무 일정 확인·등록
  • Google API로 받은 정보는 위 목적에만 쓰며, 판매하거나 광고에 이용하거나 제3자에게 제공하지 않습니다.
  • 연구소의 Google API 사용자 데이터 이용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.
  • 인증 토큰은 연구소 관리 PC에만 저장하며 외부로 전송하지 않습니다.
  • 연동 해제는 Google 계정 > 타사 앱 액세스에서 언제든지 할 수 있으며, 해제 시 연구소가 보관한 해당 토큰은 즉시 삭제합니다.

4.보유 및 이용 기간

  • 상담 문의 정보: 상담 종료 후 지체 없이 파기
  • 서비스 이용·결제 기록: 「전자상거래 등에서의 소비자보호에 관한 법률」 등 관계 법령이 정한 기간(계약·대금결제 기록 5년 등) 보관 후 파기
  • Google 인증 토큰: 연동 해제 또는 이용 목적 종료 시 즉시 삭제

5.제3자 제공 및 처리 위탁

연구소는 정보주체의 동의 또는 법령의 근거 없이 개인정보를 제3자에게 제공하지 않습니다. 현재 개인정보 처리 업무를 외부에 위탁하지 않으며, 위탁이 필요해지면 이 방침을 통해 미리 알립니다.

6.파기 절차와 방법

보유 기간이 끝나거나 처리 목적이 달성된 개인정보는 지체 없이 파기합니다. 전자 파일은 복구할 수 없는 방법으로 삭제하고, 종이 문서는 분쇄하거나 소각합니다.

7.정보주체의 권리와 행사 방법

정보주체는 언제든지 자신의 개인정보에 대한 열람·정정·삭제·처리정지를 요구할 수 있습니다. 아래 연락처로 요청하시면 지체 없이 조치합니다.

8.안전성 확보 조치

  • 개인정보와 인증 토큰은 접근이 제한된 연구소 관리 PC에 보관
  • 저장소 공개 금지 및 비밀정보 업로드 차단 장치 운영
  • 개인정보를 다루는 인원 최소화
