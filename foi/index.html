공공기관 정보공개 업무 지원

정보공개 답변서 작성기

정보공개 청구에 대한 결정통지서 초안을 만들고, 공개 자료 속 개인정보·업체명을 HWP 서식 그대로 가려(블럭 처리) 드립니다.

접속하기

서비스 주소를 준비하고 있습니다. 잠시 후 다시 확인해 주세요.

작성기 로그인 회원 가입 아이디·비밀번호 찾기

처음 접속하면 연결 안내 화면이 한 번 나올 수 있습니다. Visit Site 버튼을 누르면 작성기로 이동합니다.

이용 순서

  1. 가입기관명·아이디·이메일 입력
  2. 바로 사용승인 없이 즉시 로그인
  3. 답변서 초안자료를 끌어다 놓고 결정통지서 HWP 작성
  4. 블럭 처리가릴 이름·업체명 입력 후 HWP 내려받기

주요 기능

  • 「공공기관의 정보공개에 관한 법률」 제9조 비공개 사유를 반영한 결정통지서 초안 (법제처 법령 API 연동)
  • HWP·HWPX 원본 서식 유지 가림, PDF 영구 가림, Word·엑셀 가림본 + HWPX 변환본, 블럭처리 내역서
  • 기관별 계정 관리, 청구 건별 이력 보관(구글드라이브), 청구서 자동 인식, 관리자 통계·이용 기록
